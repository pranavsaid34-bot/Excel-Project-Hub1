# 📊 Excel Amazon Sales Dashboard

An interactive Excel dashboard built from scratch to analyze e-commerce sales performance across 2023–2024. It turns ~40,000 raw order records into clear KPIs and visuals using PivotTables, PivotCharts, and a custom-designed dashboard layout.

## 🔍 Project Overview
The dataset contains order-level details: customer, product, category, brand, quantity, pricing, discount, tax, shipping, payment method, order status, and location. The goal was to clean and model this data, then present the key business metrics on a single, easy-to-read dashboard.

## 📁 Project Structure
| Sheet | Purpose |
|---|---|
| `Data` | Raw order data (39,966 rows, 23 columns) |
| `Data Cal` | Pivot tables and calculations |
| `Top 10 products` | Ranked product analysis |
| `KPI'S` | KPI definitions and colour palette |
| `Dashboard Design` | Layout/design workspace |
| `Dashboard` | Final interactive dashboard |
